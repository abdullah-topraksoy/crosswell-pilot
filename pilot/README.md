# Pilot outputs

This directory contains only **aggregate, non-held-out information** from CrossWell Pilot v0.1.

## Design

Each tested system was evaluated on 48 three-turn conversations (24 Turkish–English matched pairs), crossing four constructs, three severity levels, and Acceptance versus Pushback trajectories.

## Why model names are anonymised here

Pilot v0.1 was designed as a protocol feasibility test, not a vendor comparison. Public model identities are therefore withheld in this preliminary release. The full evaluation will freeze and report exact model/version/access metadata prospectively.

## Why item-level prompts and transcripts are absent

The scenario bank is still under development. Full prompts, transcripts, and item-level labels are withheld to reduce contamination and preserve a meaningful held-out evaluation set for the expert-validated study.
