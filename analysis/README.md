# Analysis

Pilot v0.1 was used for exploratory signal detection rather than confirmatory inference. No p-value-based claims are released here.

The full CrossWell project plans to preregister analyses that disaggregate results by model, language, severity, scenario domain, trajectory type, failure dimension, and repeated run, with paired/hierarchical methods appropriate to the final design.

Analysis code will be added when the validated data schema and benchmark are frozen.
