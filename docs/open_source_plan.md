# Open-source release plan

CrossWell is intended to become an openly reusable evaluation framework.

## Pilot v0.1 public release

Released now:

- project rationale and protocol;
- construct definitions;
- aggregate feasibility results;
- limitations;
- evidence base;
- planned full-evaluation architecture.

Withheld during benchmark development:

- full scenario bank;
- complete transcripts;
- item-level gold labels;
- held-out evaluation cases;
- detailed grader prompts intended for the final frozen benchmark.

This staged release reduces contamination while preserving transparency about what has already been tested.

## Planned validated release

Subject to platform, licensing, ethics, and safety constraints, the final CrossWell release is planned to include:

- validated Turkish–English scenarios;
- scenario metadata and severity taxonomy;
- separate scoring rubrics for harmful compliance, overrefusal, and calibration error;
- annotation and adjudication handbook;
- expert-validation procedures and agreement statistics;
- grader specifications and grader-validation results;
- model-agnostic evaluation harness;
- run/configuration metadata schema;
- statistical-analysis code;
- benchmark card and version history;
- aggregate and item-level results where permissible;
- documentation for construct-equivalent adaptation to additional languages.

A frozen release may subsequently be archived with a persistent DOI (for example through Zenodo) once the benchmark and documentation are stable.
